C-h k C-h k runs the command describe key on the key C-h k itself. C-h b lists all keybindings, while C-h k gives targeted information on a specific key sequence. So C-h b is for global reference, whereas C-h k is for individual look up. In this case, we're using C-h k to inspect what the C-h k command does.

C-h k M-SPC runs describe-key on M-SPC. M-SPC is bound to the command cycle-spacing, which cycles through different whitespace configurations: one space, no space, and original spacing.
